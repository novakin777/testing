# Лабораторные работы по тестированию

Репозиторий содержит четыре лабораторные работы для Visual Studio 2022. Каждая работа находится в отдельной папке и имеет собственный файл решения `.sln`.

## Что нужно установить

- Visual Studio 2022 с компонентом разработки для .NET;
- .NET SDK 8.0.

Для лабораторных работ 3 и 4 нужна рабочая нагрузка «Разработка классических приложений на C++» со средствами MSVC v143 и Windows SDK.

После открытия решения Visual Studio может предложить восстановить пакеты. Нужно дождаться завершения восстановления, прежде чем запускать программу или тесты.

## Запуск лабораторной работы 1

1. Открыть файл `Лабораторная работа 1/Лабораторная работа 1.sln`.
2. Нажать зелёную кнопку запуска.
3. Выбрать `1` для запуска программы или `2` для запуска простых проверок.

В этой работе используется метод предугадывания ошибок. Основная программа находится в `Program.cs`, а простые проверки вынесены в `Tests.cs`, чтобы код программы и проверки не смешивались.

## Запуск лабораторной работы 2

1. Открыть файл `Лабораторная работа 2/Лабораторная работа 2.sln`.
2. Для запуска программы нажать зелёную кнопку.
3. Для запуска модульных тестов открыть `Тест -> Обозреватель тестов` и нажать `Запустить все`.

Во второй работе программа рассчитывает факториал, определяет чётность числа и находит большее из двух чисел. В `Tests.cs` находятся восемь модульных тестов MSTest. Обычный запуск программы и запуск тестов выполняются отдельно.

## Если программа не запускается

1. Убедиться, что открыто решение нужной лабораторной работы, а не отдельный файл `.cs`.
2. В меню `Сборка` выбрать `Пересобрать решение`.
3. Проверить, что в качестве запускаемого проекта выбрана текущая лабораторная работа.
4. Для второй лабораторной работы дождаться восстановления NuGet-пакетов MSTest.

## Запуск лабораторной работы 3

1. Открыть файл `Лабораторная работа 3/Лабораторная работа 3.sln`.
2. Нажать зелёную кнопку запуска.
3. Выбрать `1`, чтобы вывести в консоль список смежности графа.
4. Выбрать `2`, чтобы запустить проверки графа.

Третья работа выполнена на C++. Класс графа находится в `Graph.h` и `Graph.cpp`, основная программа — в `Program.cpp`, проверки — в `Tests.cpp`. Отчёт подготовлен отдельным файлом в формате DOCX.

В программе находятся шесть проверок класса `Graph`. Фрагмент `ReadNumber` проверяется отдельно в первой лабораторной работе: выбрать пункт `1`, для A ввести `25`, либо `abc` и `25`, либо `1000000001`, `-1000000001` и `-4`; для B во всех случаях ввести `1`. Ожидаются соответственно ноль, одно и два сообщения об ошибке, а итоговые значения равны `25`, `25` и `-4`.

## Запуск лабораторной работы 4

1. Открыть файл `Лабораторная работа 4/nagrtest.sln` в Visual Studio 2022.
2. Выбрать конфигурацию `Release` и платформу `x64`, собрать решение и запустить без отладчика (`Ctrl+F5`).
3. Ввести число виртуальных пользователей: `50` или `500`.
4. Ввести шаг запуска потоков: `100` мс для основных опытов или `0` мс для дополнительного сравнения без пауз.
5. Для следующего опыта запустить программу заново с другими параметрами. Исходный код менять не требуется.

Каждый пользователь выполняет 20 запросов: всего 1000 или 10 000. Программа выводит число успешных и ошибочных запросов, долю ошибок, полное время, TPS по успешным запросам, среднюю задержку, P95 и P99. Задержки и ошибки моделируются случайно, поэтому результаты повторных запусков отличаются.

Для сборки требуется Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++» и Windows SDK. В репозитории находятся исходный код и файлы проекта; результаты сборки Visual Studio создаёт локально.
