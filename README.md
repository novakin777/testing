# Лабораторные работы по тестированию

Репозиторий содержит две лабораторные работы на C# для Visual Studio 2022 и .NET 8.

## Запуск лабораторной работы 1

1. Открыть файл `Лабораторная работа 1/Лабораторная работа 1.sln`.
2. Нажать зелёную кнопку запуска.
3. Выбрать `1` для запуска программы или `2` для запуска простых проверок.

## Запуск лабораторной работы 2

1. Открыть файл `Лабораторная работа 2/Лабораторная работа 2.sln`.
2. Для запуска программы нажать зелёную кнопку.
3. Для запуска модульных тестов открыть `Тест -> Обозреватель тестов` и нажать `Запустить все`.
